# LiaKratts

Emilia's Super Speedy Hide and Seek: a browser game for Lia. Emilia the shy phoenix hides in the trees while Martin and Chris search, and zooms from tree to tree in a blur so they never see her.

Play it at https://eternityslyre.github.io/liakratts/

Everything is in `index.html` (no build step). Progress is saved in the browser.
